Elham — Help Desk Migration: Jira to ClickUp

Cut the licence bill, kept the discipline, and made ownership impossible to dodge.

Client / DonorInternal — Elham
LocationRiyadh, Saudi Arabia
RoleProcess Automation Engineer
TeamSole delivery
Duration2 months
ApproachWorkflow re-architecture, not lift-and-shift
ScaleCompany-wide support function

The Mandate

Migrate the internal support ticketing system off Jira and onto ClickUp — cutting tool cost while unifying operational, technical, instructional design, and bug tickets inside one workspace with automated routing.

The Challenge

Migrating a live support function without service interruption, across departments that each held a different working definition of what a ticket actually is.

The Execution

  • Designed and built the centralised workflow from scratch rather than lifting Jira's structure across — a migration is an opportunity to fix the process, not preserve it.
  • Automated routing so every request type reaches the owning team without a human dispatcher.
  • Linked support tickets directly to project tasks and responsible teams, making accountability structural rather than cultural.
  • Consolidated daily operations into a single workspace, eliminating tool-switching and the fragmentation it causes.
  • Enabled an external support system with emailing and auto-response for technical support.

Results Delivered

  • Full support function migrated off Jira — licence cost eliminated ($500 monthly).
  • Centralised performance tracking across support and project functions inside one platform.
  • Task ownership made explicit and traceable end to end.
  • Cross-department workflows unified under the company's primary project management tool.
  • External ticketing system through email fully automated.
